# xiting910/.github

这是我的 GitHub 个人主页配置仓库（特殊仓库），用于统一管理我的个人主页简介和所有仓库的默认社区模板。

## 内容说明

| 文件/目录                          | 用途                                 |
| ---------------------------------- | ------------------------------------ |
| `profile/README.md`                | 显示在我的 GitHub 个人主页顶部的简介 |
| `.github/ISSUE_TEMPLATE/`          | 我的所有仓库默认使用的 Issue 模板    |
| `.github/PULL_REQUEST_TEMPLATE.md` | 我的所有仓库默认使用的 PR 模板       |
| `CODE_OF_CONDUCT.md`               | 我的所有仓库默认使用的行为准则       |
| `CONTRIBUTING.md`                  | 我的所有仓库默认使用的贡献指南       |
| `SECURITY.md`                      | 我的所有仓库默认使用的安全策略       |
